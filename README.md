
# Hotel Management System

## About the Project
The Hotel Management System is a web application designed to manage hotel operations in one place.

## Features
- Admin login
- Room management
- Room booking
- Customer management
- Check-in and check-out
- Billing management
- Dashboard
- Food ordering

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

## Project Structure
- `server.js` - Main server file
- `seed-rooms.js` - Initial room data setup
- `database/` - Database connection
- `routes/` - Backend routes
- `public/` - Website pages

## Installation
1. Install Node.js.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required dependencies using `npm install`.
5. Start the application using `npm start`.
6. Open `http://localhost:3000` in your browser.
